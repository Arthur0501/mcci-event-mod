# mcci-event-mod
With this mod, you can do a slash command to save the stash with coordinate, rarity and (eventually) a comment. This mod is helpful for wiki writters, because they need to get all stashes coords to make wiki map.
You can find all the stashes at this [https://mcci-event.vercel.app/](url).
